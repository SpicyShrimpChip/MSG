# 위키 교훈 한 건 남기기

작성 규칙의 원문은 `docs/wiki/README.md`의 "작성 규칙"이다. 아래 순서는 그 규칙을 빠뜨리지 않기 위한 절차이고, 규칙 내용 자체는 README를 따른다.

1. `docs/wiki/README.md`의 "작성 규칙"과 "목차"를 읽는다.
2. 남길 가치가 있는지 판단한다. 당연한 것이나 이미 `CLAUDE.md`에 규칙으로 있는 것이면 쓰지 않고 사용자에게 그렇게 말한다.
3. 분류 파일을 고른다: 화면·프론트 코드는 `frontend.md`, 백엔드는 `backend.md`, CI·Git·배포·도구는 `tooling.md`, 문서·진행 방식은 `process.md`.
4. 그 파일과 목차에서 같은 주제의 교훈이 있는지 찾는다. 있으면 새로 쓰지 않고 그 항목을 고친다.
5. 파일 끝에 한 건을 붙인다. 제목 줄은 그 파일의 기존 항목과 같은 수준(`## `)으로 쓰고, 본문은 README의 "한 건의 형식"(상황·원인·해결·다음에는)을 따른다. 날짜는 오늘, PR 번호를 아직 모르면 브랜치 이름을 적는다.
6. README 목차에서 그 파일의 목록 끝에 제목만(날짜·PR 없이) 한 줄 추가한다.
7. 붙인 글에 README가 금지한 것(비밀값, 내 컴퓨터 경로, 서버·계정 주소, 연락처, 고치지 않은 보안 허점)이 없는지 다시 본다.
8. 추가한 제목과 파일을 사용자에게 한 줄로 알린다. 커밋은 사용자가 요청할 때만 한다.
