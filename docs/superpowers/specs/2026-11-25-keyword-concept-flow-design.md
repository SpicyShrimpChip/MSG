# 자료 본문 전송이 꺼져 있을 때 키워드 개념으로 커리큘럼 끝내기 (#212)

## 왜

운영 설정(`MATERIAL_CONTENT_ENABLED=false`)에서는 자료에서 핵심 개념을 뽑지 못해 커리큘럼 개념이 과목 키워드가 된다.
서버 규칙(`CurriculumFlowBuilder.need()`)은 이미 키워드 개념을 "사전평가 제출 뒤 키워드 퀴즈를 하나라도 풀면 STEP 2 끝"으로 본다.
그런데 STEP 2 카드의 "개념 보기"가 키워드 개념도 자료 상세 "핵심 개념" 탭(막힌 뽑기 버튼만 있음)으로 보내서,
실사용자 테스트 참가자가 사전평가 다음에서 멈춘다. 화면이 서버 규칙대로 안내하게 맞춘다.

## 목표

- 키워드 개념만 있는 과목도 STEP 1 → 4를 막힘 없이 끝낼 수 있다.
- 학습 진도(커리큘럼 진행 막대, 대시보드 요약 칸·자세한 진도)가 키워드 개념일 때도 의미 있는 숫자를 보여 준다.
- "AI 분석 전", 같은 화면에 두 번 나오는 "전송 꺼짐" 안내를 실제 상태에 맞춘다.

## 하지 않는 것

- DB·API 응답 형식 변경(새 마이그레이션 없음, 키워드 개념의 "학습 완료" 기록 없음).
- 자료 본문 전송 켜기, 처리방침 변경.
- 올린 파일 열기·내려받기(지금 API가 없고, 저장·개인정보 검토가 필요한 별도 기능).
- 서버 단계 판정 규칙 변경.

## 검토한 방법

| 방법 | 장점 | 단점 |
| --- | --- | --- |
| **A. 키워드 흐름 정리 (선택)** | 화면 위주, DB·API 그대로, 제출 전에 넣어도 안전 | 키워드 개념에는 "공부했어요" 기록이 없고 퀴즈 결과만 근거 |
| B. 키워드 개념에도 학습 완료 기록 | 진도가 자료 개념과 똑같이 쌓임 | V6 마이그레이션·API·확인 퀴즈 연결 변경, 주미 님 API 영향 |
| C. 자료 본문 전송 켜기 | 자료 개념 흐름이 그대로 동작 | 11/23 비용 결정과 충돌, 처리방침 7·8번 개정 필요 |

11/25 지환 선택: A.

## 바꾸는 것

1. **커리큘럼 STEP 2 (`CurriculumPage` `ConceptStudyStep`)**
   - 학습 기록이 없는 키워드 개념(`concept.study === null`) 카드: "개념 보기" 대신 **"퀴즈로 확인하기"**(STEP 3 `KeywordConceptRow`와 같은 `conceptQuizLink`)를 둔다. 칩은 "퀴즈로 확인 (과목 키워드)".
   - 카드 안내: "올린 자료로 이 개념을 공부한 뒤 퀴즈로 확인해요."
   - 맨 위 키워드 안내(`conceptSource === 'course'`): 전송이 꺼져 있으면 "지금은 자료에서 개념을 뽑지 않아 과목 키워드로 공부해요. 퀴즈를 하나 풀면 다음 단계로 넘어가요.", 켜져 있으면 지금 문구(핵심 개념 탭에서 뽑기) 유지.
   - 진행 막대(`StudyProgressBar`): 자료 개념이 없으면 "과목 키워드 N개 중 M개를 퀴즈로 확인했어요"(M = `practiceGradedCount > 0`인 개념 수) + 막대.
2. **서버 STEP 2 요약 문장 (`CurriculumFlowBuilder.studySummary`)**: 자료 개념이 없을 때 "자료에서 핵심 개념을 뽑으면 …" → "자료로 공부한 뒤 개념마다 퀴즈로 확인해요. 퀴즈를 풀면 다음 단계로 넘어가요." (문장만, 필드 그대로)
3. **대시보드 학습 진도 (`SummaryStrip` `ProgressTile`, `StudyProgressPanel`)**: 자료 개념이 없고 개념이 있으면 1번과 같은 키워드 퀴즈 확인 수를 보여 준다. "자료에서 핵심 개념을 뽑으면 진도를 세요"는 개념이 하나도 없을 때만.
4. **자료 목록·상세 상태 문구**: `uploaded` 상태의 "AI 분석 전"을 "저장됨"으로, 자료 상세 안내 제목 "아직 AI 분석 전이에요"를 상태에 맞는 문구로.
5. **사전·사후평가 화면 (`AssessmentPage`)**: 전송이 꺼져 있으면 "자료 본문으로 문제 만들기" 체크 칸을 그리지 않는다(꺼진 이유는 위 핵심 개념 칸에 한 번만).

색: 진도 숫자·막대는 코드가 센 값이라 파랑(`primary`). AI 보라 쓰지 않음.

## 확인

- 프론트 lint·format·test·build, 백엔드 test.
- 목업에서 키워드뿐인 과목(정보보호개론 외)으로 STEP 1 → 4 화면 확인, 실제 서버 모드(전송 꺼짐)로 사전평가 제출 → STEP 2 카드 → 퀴즈 하나 풀기 → STEP 3 표시까지.
- 정보보호개론(자료 개념 있음) 화면은 그대로인지.

## 빌더 판단에 맡기는 것

- 키워드 퀴즈 확인 수를 세는 도우미 위치(`utils/`)와 이름, 문구의 세부 표현.
