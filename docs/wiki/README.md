# 개발 교훈 위키

개발하면서 겪은 에러·시행착오와 해결을 모아 두는 곳이다. 같은 실수를 다시 하지 않고, Claude Code가 작업 전에 읽어 참고하게 하려는 목적이다(루트 `CLAUDE.md`의 "작업 방식" 참고).

## 작성 규칙

- **다시 겪으면 시간을 잃는 것만 쓴다.** 당연한 것, 이미 `CLAUDE.md`에 규칙으로 적힌 것은 쓰지 않는다. 규칙이 있는 내용은 어디에 있는지만 가리킨다.
- **한 건은 5줄 안쪽으로 짧게.** 아래 형식을 따른다.
- 건마다 **날짜와 관련 PR 번호**를 적는다. 추정은 쓰지 않고, 확인한 것만 쓴다.
- 에러를 해결했거나 시행착오를 겪은 **같은 PR에** 한 건을 추가한다.
- **이 레포는 공개다.** 아래는 절대 쓰지 않는다.
  - 비밀번호·토큰·API 키 값, 테스트 계정 정보
  - 내 컴퓨터의 경로, 서버·DB 호스팅의 주소·계정, IP
  - 팀원·멘토의 이메일·연락처
  - 아직 고치지 않은 보안 허점(고친 뒤에 교훈으로 쓴다)
- 환경변수는 이름만 쓰고 값은 쓰지 않는다.

### 한 건의 형식

```markdown
### 제목: 증상 한 줄 (YYYY-MM-DD, #PR번호)

- 상황: 어떤 작업을 하다가 생겼는지
- 원인:
- 해결:
- 다음에는: 미리 확인할 것
```

## 목차

작업을 시작하기 전에 해당 파일의 제목을 훑는다. Claude Code 세션은 시작할 때 이 제목 아래부터 파일 끝까지를 그대로 읽는다(`.claude/settings.json`의 SessionStart 훅). 그래서 목차는 이 문서의 맨 끝에 두고, 제목(`## 목차`)을 바꾸면 훅 명령도 같이 고친다.

### [frontend.md](frontend.md): 프론트엔드

- 직접 만든 글자 크기 토큰이 `cn()`에서 지워진다
- 화면 모드 전환을 색 섞기로 하면 글자가 잠깐 사라진다
- 굴절 유리를 넓게 걸면 스크롤이 느려진다
- `width: auto`는 전환되지 않는다
- 직접 쓴 CSS는 `components` 레이어에 둬야 Tailwind 클래스가 이긴다
- axios 기본 헤더가 JSON이면 FormData 업로드에서 파일이 빠진다
- zip 로컬 헤더의 크기 칸이 0xFFFFFFFF면 ZIP64 확장 필드를 읽는다
- 코드 블록 안의 글자는 마크다운 플러그인으로 못 칠한다: CSS Custom Highlight로 짚는다
- 목업 화면 상단바만 로그인 상태가 된다: 포트가 달라도 쿠키는 같이 쓴다
- 오류 화면의 "다시 시도"를 눌러도 같은 오류 화면이 남는다
- 배포 직후 열려 있던 탭에서 화면을 옮기면 영어 기본 오류 화면이 뜬다
- JS 정규식을 러스트로 옮기면 결과가 달라지거나 느려진다
- thinking-orbs 구슬이 밝은 화면에서 안 보이고 32px에서 비어 보인다
- border-beam 빛이 밝은 화면에서 거의 안 보이고 화면 모드를 안 따라간다
- 좌우로 나눈 표·상세에서 표 옆이 크게 빈다
- `disabled={isPending}`만으로는 저장 버튼 더블클릭을 못 막는다
- `src` 안 테스트에서 `node:` 모듈을 가져오면 build가 깨진다
- 화면에서 고른 대화가 분석 때 "키워드가 없다"로 빠질 수 있다: 프론트·백엔드 키워드 규칙을 같이 바꾼다
- ESLint 규칙에 파일별 예외를 걸면 그 파일에서 같은 규칙의 다른 항목도 사라진다
- Tailwind 4의 `outline-none`은 고대비 모드에서 포커스를 지운다: `outline-hidden`을 쓴다
- 체험 모드에서는 마이페이지가 안 떠 확인 창 여러 개를 화면으로 볼 수 없다
- `src/test/` 초기화 파일의 `vi.mock('@/…')`이 아무 일도 하지 않는다
- 대시보드가 불러오는 동안 짧은 회색 틀을 보여 주면 다 그린 뒤 아래 구역이 밀린다
- 닫히며 사라지는 햄버거 메뉴의 링크로 옮기면 포커스가 본문으로 가지 않는다
- 컴포넌트와 도우미 파일 이름이 대소문자만 다르면 macOS에서 import가 엉뚱한 파일로 풀린다
- 포커스 직후 읽은 계산 스타일이 옛 값이라 포커스 표시가 안 붙은 줄 안다
- 템플릿 문자열 클래스를 `cn()`으로 바꾸면 줄 높이가 사라질 수 있다

### [tooling.md](tooling.md): CI·Git·배포

- 패키지가 늘어난 뒤에는 다른 컴퓨터에서 `npm ci`를 다시 한다
- Prettier 검사는 CI가, 고치는 건 커밋 훅이 한다
- 도커: `docker --version`은 되는데 연결 오류가 난다
- VS Code PostgreSQL 확장 접속 오류 세 가지
- 백엔드 CI를 필수 검사로 켜는 순서
- npm 12가 공식 registry 파일까지 막는다(Renovate 임시 제한)
- Claude는 강제 푸시가 막혀 있다
- GitHub Actions 대기열이 길 때
- Vercel 환경변수가 빠지면 화면이 `/api`를 실제로 부른다
- 빌드 폴더에 `파일 2.sql` 같은 복사본이 생기면 테스트가 깨진다
- `bootRun`이 MySQL 드라이버를 찾으며 뜨지 않는다
- Windows Git Bash에서 curl로 한글 JSON을 보내면 400이 난다
- 개발 서버를 다른 포트로 띄우면 실제 API 요청이 전부 403이다
- 쌓은 PR을 squash 머지하면 다음 PR이 충돌하고, base가 main이 아니면 백엔드 CI가 돌지 않는다
- Git Bash에서 `docker compose exec ... /data/...`의 경로가 Windows 경로로 바뀐다
- Claude의 명령에 읽기 금지 파일이 섞이면 같은 명령의 다른 수정도 실행되지 않는다
- 셸 `cat >`로 새 파일을 만들다 같은 이름의 기존 파일을 덮었다
- 워크트리에서 미리보기 서버를 띄우면 원래 체크아웃의 화면이 뜬다
- 워크트리에서 `pgTest`를 돌리면 DB 비밀번호가 없어 접속하지 못한다
- 워크트리에서 백엔드만 고쳐도 푸시가 `tsc` 오류로 막힌다
- CI(4 vCPU)에서 테스트를 나눠 돌려도 빨라지지 않았다: 러너 편차가 효과보다 크다
- 새로 만든 서브에이전트·스킬은 바로 불러지지 않는다: 훅은 바로, 에이전트·스킬은 몇 분 뒤 읽힌다

### [backend.md](backend.md): 백엔드 (초안, 주미 님 확인 필요)

- 머지된 마이그레이션은 고치지 않고 새 버전을 추가한다
- 앱 DB 계정과 마이그레이션 계정을 나눈다
- 역할은 토큰이 아니라 요청마다 DB에서 읽는다
- 탭 두 개가 동시에 로그인을 연장하면 둘 다 로그아웃된다
- 공지 본문은 HTML로 해석하지 않고 글자 그대로 저장한다
- MySQL에서 PostgreSQL로 옮길 때 H2 테스트를 지키는 법
- 긴 글에 쓰는 정규식이 1MB 요청 하나를 몇 분 동안 붙잡는다
- `@Enumerated(STRING)` 열로 정렬하면 enum 순서가 아니라 글자 순이다
- 머지 전 마이그레이션을 고치면 `pgTest`가 Flyway 검증 오류로 모두 실패한다
- 응답에 새 필드를 더했더니 다른 사람의 계약 테스트가 깨졌다
- 저장 직후 응답의 시각이 다시 읽은 값과 달라 Linux CI에서만 테스트가 깨진다
- 키를 넣었는데 퀴즈가 설정한 첫 모델이 아닌 다른 모델로 만들어진다
- 대화 하나가 길면 분석에서 통째로 빠져 "키워드가 들어간 대화가 없어요"가 뜬다
- 반복문을 공용 도우미로 합쳤더니 개념 뽑기의 시간 초과 동작이 바뀌었다
- AI 시간 예산이 프록시 한도보다 길면 배포 뒤 화면만 실패로 보인다
- NUL 문자가 든 대화가 "다른 요청과 겹쳐"(409)로 계속 실패한다: PostgreSQL은 NUL을 거절하고 H2는 받는다
- 모델이 모두 실패한 분석이 "최근 분석"이 되어 이전 결과를 덮었다
- 테스트 공용 초기화의 설정값이 `@TestPropertySource`를 이겼다
- 카카오는 동의하는 순간 연결된다: 가입을 거절하면 연결만 남는다
- 개발자 PC의 `backend/.env`에 키를 넣자 탈퇴 테스트가 로컬에서만 깨졌다
- `afterCommit`에서 외부 API를 부르면 그동안 DB 연결을 잡는다
- 설정 record에 생성자를 하나 더 만들었더니 앱이 뜨지 않는다
- 영문 개념 이름을 부분 문자열로 찾으면 다른 낱말 안에서도 잡힌다
- 테스트에서만 쓰던 저장소 메서드를 지웠더니 과목 조건 때문에 테스트가 깨졌다
- 직접 넣는 키의 엔티티를 `save`로 "없으면 만들기" 하면 merge가 동시에 올린 수를 덮어쓴다
- ArchUnit 호출 규칙이 `OpenAiClient`가 `HttpLlmClient.complete`를 부른다고 잡는다
- 점수 합 비율 하나를 모든 문제에 같은 값으로 주어 서술형 하나가 숙련도를 "강점"으로 올렸다
- 늦게 끝난 채점 실행이 그사이 시작된 다시 채점의 답을 실패로 바꿨다
- 사용자 행을 잠근 채 PDF를 읽어 같은 사용자의 다른 요청이 잠금 시간 초과로 500이 됐다
